# keywords — скилл для Claude Code: ключевые слова и заголовки по-русски

Скилл подбирает ключевые слова и заголовки под площадку (YouTube, Shorts, VK Видео, Rutube, Дзен, Хабр/vc.ru, Telegram, Reels):

- снимает **подсказки поиска YouTube** — что люди набирают и в каком порядке;
- снимает **частоты Яндекс Вордстата** (широкую и точную) через Yandex Cloud Search API **вашим** ключом;
- сводит всё в таблицу «фраза → место в подсказках → частота»;
- предлагает 3–5 заголовков и проверяет их по правилам площадки.

Автор: STEREO AI · Telegram [t.me/pro_stereo_ai](https://t.me/pro_stereo_ai) · YouTube [@pro_stereo_ai](https://www.youtube.com/@pro_stereo_ai). Версия 1.0, 29.09.2026.

## Что внутри

```
keywords/
├── SKILL.md            инструкция для Claude (как собирать семантику и проверять заголовки)
├── README.md           этот файл
├── .env.example        шаблон для ключей Yandex Cloud
├── data/ws_cache.json  локальный кэш частот (пустой; заполняется сам)
└── tools/
    ├── yt_suggest.py   подсказки поиска YouTube (ключ не нужен)
    ├── ws.py           частоты Вордстата через Yandex Cloud Search API
    └── merge.py        сводная таблица
```

Нужен только Python 3.8+ — сторонних библиотек нет.

## Как поставить в Claude Code или Codex

1. Распакуйте архив — внутри папка `keywords`.
2. Положите её в папку скиллов своего агента:
   - **Claude Code, для всех проектов:** `~/.claude/skills/keywords/` (Windows: `C:\Users\<имя>\.claude\skills\keywords\`); только для одного проекта — `<папка проекта>/.claude/skills/keywords/`;
   - **Codex (CLI, приложение, IDE):** `~/.agents/skills/keywords/` (Windows: `C:\Users\<имя>\.agents\skills\keywords\`); только для одного репозитория — `<репозиторий>/.agents/skills/keywords/`. Папку копируйте, а не делайте на неё ссылку: по ссылке Codex находит скиллы не всегда.
3. Проверьте Python: `python --version` (или `python3 --version`) — 3.8 или новее.
4. Скопируйте `.env.example` в `.env` и впишите ключи (ниже).
5. Перезапустите агента и попросите, например: «подбери ключевые слова и название для ролика про то, как выложить видео на ютуб». Агент сам подхватит скилл; в Codex его можно вызвать и явно — `$keywords` или через меню `/skills`.

Проверка без Claude:

```
python tools/yt_suggest.py --out s.json "как выложить видео на ютуб"
python tools/ws.py "как выложить видео на ютуб"
```

Подсказки YouTube работают сразу. Для частот Вордстата нужен ключ.

## Где взять ключ Yandex Cloud для Вордстата

Вордстат доступен через **Yandex Cloud Search API** (метод `wordstat/topRequests`). Понадобятся два значения: **ID каталога** и **API-ключ сервисного аккаунта**.

1. Зайдите в консоль [console.yandex.cloud](https://console.yandex.cloud/) под своим Яндекс ID. Если облака ещё нет — консоль предложит создать облако и каталог (обычно `default`). Для платных сервисов понадобится платёжный аккаунт — условия и тарифы Search API смотрите в [документации Search API](https://yandex.cloud/ru/docs/search-api/) (проверить актуальные цены и бесплатную квоту перед подключением).
2. **ID каталога (`YC_FOLDER_ID`).** Откройте каталог в консоли — ID показан рядом с его названием (строка вида `b1g…`). Скопируйте кнопкой рядом.
3. **Сервисный аккаунт.** В каталоге: «Identity and Access Management» → «Сервисные аккаунты» → «Создать». Назначьте роль на каталог для доступа к Search API — у нас работала `search-api.webSearch.user`. Если консоль предлагает отдельную роль для Вордстата — назначьте и её.
4. **API-ключ (`YC_API_KEY`).** Откройте созданный сервисный аккаунт → «Создать новый ключ» → «Создать API-ключ». Если консоль спросит область действия — выберите ту, что относится к Search API. Секрет показывается **один раз** — сразу скопируйте его (строка вида `AQVN…`).
5. Впишите оба значения в `.env`:
   ```
   YC_API_KEY=AQVN...
   YC_FOLDER_ID=b1g...
   ```

`.env` никому не отправляйте и не выкладывайте в git (он уже в `.gitignore`).

## Лимиты и ошибки

- **Квота:** около 100 запросов в час (на сентябрь 2026; ваша квота — в консоли, раздел квот Search API). Одна фраза = один запрос, `--both` = два. Всё снятое кладётся в `data/ws_cache.json`, повторный запуск квоту не тратит.
- **429** — квота кончилась: скрипт скажет, сколько фраз не снято, перезапустите позже.
- **401 / 403** — неверный ключ, не тот каталог или у сервисного аккаунта нет роли.
- **Регион:** по умолчанию 225 — вся Россия; `--region 213` — Москва. Коды — дерево регионов Вордстата (метод `getRegionsTree` того же API).

## Честно о цифрах

- Вордстат — это поиск Яндекса, а не YouTube. Абсолютные числа на YouTube меньше, пропорции близки.
- YouTube объёмов поиска не отдаёт — только порядок подсказок. Первое место = самый частый вариант.
- Скилл не придумывает частоты: нет данных — в таблице будет «—».
