# Ключевики и заголовки

Инструменты в `tools/` (Python 3.8+, без зависимостей):

| Скрипт | Что делает |
|---|---|
| `yt_suggest.py` | подсказки поиска YouTube (регион РФ, русский), место в списке = сигнал популярности. `--alphabet` добивает «сид + а…я / a…z» |
| `ws.py` | Вордстат через Yandex Cloud Search API v2 (`topRequests`) с ключом пользователя из `.env` (`YC_API_KEY`, `YC_FOLDER_ID`). Широкая по умолчанию, `--exact` / `--both`, `--top N` — самые частые хвосты. Локальный кэш `data/ws_cache.json` — повтор не тратит квоту |
| `merge.py` | таблица на тему: фраза × место в подсказках × широкая × точная |

**Ключей нет** (`ws.py` пишет «Нет YC_API_KEY») — скажи человеку открыть `README.md`, раздел про ключ Yandex Cloud. Без ключа работают подсказки YouTube, но частот не будет — так и напиши, не придумывай цифры.

**Квота Вордстата — около 100 запросов в час** (на 09.2026, проверь свою квоту в консоли Yandex Cloud), одна фраза = один запрос. Сначала кэш, потом новые фразы. Упёрлись в 429 — скрипт скажет, сколько осталось; дожать позже.

## Конвейер

1. **Затравки.** Тема + ВСЕ написания, как пишут люди: «чат gpt», «чат гпт», «chat gpt», «chatgpt», «чатгпт». Разные написания — разные строки и в подсказках, и в Вордстате; Яндекс склеивает словоформы, но НЕ написания.
2. **Расширение по площадке.** YouTube/VK/Rutube — `yt_suggest.py` (своих подсказок VK Видео и Rutube скилл не снимает — берём YouTube + Вордстат, их ролики индексирует Яндекс). Дзен/Хабр/vc — Вордстат (`ws.py --top N`: хвосты из `results`; `associations` API — шум, скрипт их не выводит).
3. **Чистка.** Выкинуть чужой интент (иностранный язык, игры/тёзки: «codex mortis», «psn»), чужие бренды, навигационное. Сгруппировать по интенту: как сделать / сколько стоит / бесплатно / ошибка-проблема / отзыв / сравнение.
4. **Частоты.** `ws.py --both --json ws.json` по отобранным (не по всем 200 — квота).
5. **Таблица** `merge.py` → `semantika.md` в папке проекта пользователя.
6. **Выбор:** главный ключ + 2–4 вторичных НА КАЖДУЮ площадку отдельно.
7. **Заголовки** 3–5 вариантов, самопроверка (ниже), показать человеку таблицей «заголовок → какие запросы ловит (цифры)».

Пример запуска:

```
python tools/yt_suggest.py --out suggest.json "как выложить видео на ютуб" "как загрузить видео на ютуб"
python tools/ws.py --both --json ws.json "как выложить видео на ютуб" "как загрузить видео на ютуб"
python tools/merge.py --topic "загрузка видео" suggest.json ws.json > semantika.md
```

## Как читать цифры

- **SEO = охват → решает ШИРОКАЯ частота:** все запросы, где встречаются слова фразы (хвосты + словоформы). Заголовок с «чат gpt в россии» показывается и по «как оплатить чат gpt в россии», и по «…на айфон».
- **Точная (в кавычках) — проверка, ЧЬИ хвосты.** Широкая большая, а хвосты чужие — число не наше. «как сделать сайт» 84 847 широкой, 907 точной: люди ищут «…на тильде / wordpress», ролик про нейросеть туда не встанет. «бесплатный чат gpt» 201 863 / 103 567 — живой запрос, целиться можно.
- **Предлоги считаются.** «чат gpt из россии» — 5 874, «чат gpt в россии» — 27 652: один предлог меняет охват в разы.
- **Место в подсказках YouTube** — единственный сигнал YouTube о популярности (объёмов он не отдаёт). Первые места = частые.
- Вордстат — поиск Яндекса, не YouTube: абсолютные числа на YouTube меньше, пропорции близки.
- Операторы через API **работают** (проверено 28.09.2026): `"фраза"` точная, `!слово` точная форма.

(Цифры в примерах — Вордстат, Россия, в месяц, сентябрь 2026.)

## Правила по площадкам

| Площадка | Ключ где | Длина | Особое |
|---|---|---|---|
| YouTube длинное | главный ключ в первых 40–50 символах, первыми словами | ≤ 60 (лимит 100, на телефоне видно ~50) | год — только если он есть в подсказках и тема портится (оплата); ключ + в 1–2 строках описания и в главах; теги почти не влияют — только опечатки и транслит |
| YouTube Shorts | ключ голосом и текстом на экране в первые секунды | ≤ 40 | в ленте заголовок почти не важен, в поиске важен |
| VK Видео | ключ в начале; ключ в названии канала и плейлистов тоже поднимает | ≤ 60 | описание: первые ~200 символов = сниппет, 3–5 хештегов |
| Rutube | точное совпадение метаданных важнее, чем на YouTube | ≤ 60 | описание до ~250 слов, короткие теги; нерелевантные хештеги выкидывают из подборок |
| Дзен / Хабр / vc.ru | ключ в первой половине заголовка, вторичные — в лиде и H2 | Дзен ≤ ~70 (макс 128) | трафик из Яндекса → Вордстат; кликбейт Дзен штрафует |
| Telegram | название канала и @username (совпадение подстроки), первая строка поста | — | посты ищутся во вкладке «Посты»; публичное индексируется через t.me/s/ |
| Instagram Reels | первая строка подписи + текст на экране + голос | — | не больше 5 хештегов (с 12.2025) |

Правила площадок меняются — перед важным запуском сверь лимиты со справкой площадки.

## Самопроверка заголовка (каждый пункт — да/нет)

1. Главная фраза стоит **дословно в том написании, которое дал источник** («чат gpt», а не «ChatGPT»), и начинается в первых 3–5 словах.
2. Перед ключом нет слов без спроса («Plus», «Pro», «Полный гайд», «Новый») — каждое слово в начале подтверждено частотой.
3. Каждая цифра в обосновании — из `ws.py`/`yt_suggest.py` сегодня, с запросом. Нет данных — пишу «нет данных», не придумываю.
4. Длина в лимите площадки (таблица выше).
5. Год — только у быстро портящихся тем и только если есть в подсказках.
6. Заголовок свой для каждой площадки, не копия YouTube.
7. Обещание заголовка выполняется в первые 15–30 секунд видео (или в лиде статьи); без кликбейта, которого нет в контенте.
8. Бренд в официальном написании — только если его частота не меньше самого частого варианта.

## Типичные ошибки

- Писать «ChatGPT» слитно, хотя ищут «чат gpt» («чат гпт» — 1,9 млн в месяц, больше, чем «chatgpt»).
- Ставить уточнение в начало: «как оплатить chatgpt plus» — 350 запросов, «как оплатить чат gpt» — 10 187.
- Выкидывать из заголовка слово, которое ищут вместе с брендом (например, «карта …»), не проверив его частоту.
- Путать широкую и точную: для охвата смотрим широкую, точную — только чтобы проверить хвосты.
- Список фраз из Windows-файла с `\r` на конце — половина не сопоставится. `ws.py` это уже чистит.
