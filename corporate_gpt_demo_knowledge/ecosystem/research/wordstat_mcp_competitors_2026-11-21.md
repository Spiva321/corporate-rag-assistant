# Проект 3: доступ к Яндекс Вордстату через окно/бота и MCP

Дата: 2026-11-21. Черновое исследование для обсуждения, не финальное ТЗ Роме.

## Суть проекта

Дать пользователю доступ к частотам Яндекс Вордстата без самостоятельной настройки Yandex Cloud:

- через простое веб-окно;
- через Telegram-бота;
- через собственный MCP-сервер для ИИ-агентов и других продуктов.

Внутри используется наш уже работающий конвейер: VPS `/opt/seo/wordstat.py`, официальный Yandex Cloud Search API v2, кэш и квота 100 запросов в час. Не надо начинать источник данных с нуля.

## Прямые MCP-конкуренты

### Marketscore Wordstat MCP — ближайший конкурент
- URL: https://app.marketscore.ru/mcp-wordstat
- Коннектор: https://github.com/marketscore/marketscore-wordstat-mcp
- Хостовый MCP: данные и логика находятся у сервиса, пользователю не нужен ключ Yandex Cloud.
- Подключение Claude/ChatGPT через OAuth по ссылке, локальные клиенты через `npx -y marketscore-wordstat-mcp`.

Инструменты:
- `wordstat_suggest`: частоты, похожие фразы, шум, адресуемый спрос, минус-слова, разбивка по интенту и устройствам.
- `wordstat_dynamics`: 24 месяца, пик/спад, тренд год-к-году и текстовый вывод.
- `wordstat_cluster`: группы объявлений, названия, заголовки и ключи.
- `wordstat_regions`: распределение спроса по регионам и affinityIndex.
- Повтор из кэша бесплатный.

Цены:
- 1 запрос бесплатно при регистрации.
- 100 запросов — 20 ₽.
- 500 — 90 ₽.
- 1 000 — 150 ₽.
- 2 000 — 250 ₽.
- Подписки нет, кредиты не сгорают.

Это почти точно наша исходная бизнес-модель: готовый Wordstat MCP без настройки Яндекса, дешёвые пакеты и кэш.

### N1arko/yandex-wordstat-mcp
- URL: https://github.com/N1arko/yandex-wordstat-mcp
- Бесплатный MCP с открытым кодом, MIT.
- Каждый пользователь подключает собственные `YC_SEARCH_API_KEY` и `YC_FOLDER_ID`.
- `wordstat_top_requests`, `wordstat_dynamics`, `wordstat_get_regions_tree`, `wordstat_find_region`.
- Похожие запросы, ассоциации, регионы, динамика по дням/неделям/месяцам.
- Подходит как технический референс, но не как готовый сервис без настройки.

### antohins/seo-tools-mcp — standalone Wordstat
- URL: https://github.com/antohins/seo-tools-mcp
- Отдельный пакет `seo-tools-mcp-wordstat`, MIT.
- `wordstat_frequency`: широкая и точная частота, похожие запросы и ассоциации.
- `wordstat_dynamics`, `wordstat_regions`, `wordstat_regions_tree`.
- Работает через официальный Yandex Cloud Search API v2, свой API-ключ.
- Поддерживает операторы, JSON, повторные попытки 429/5xx, мультиаккаунты, stdio и HTTP-мост.
- Документация подтверждает квоту 10 rps / 100 запросов в час.
- Хороший технический референс именно для широкой+точной частоты и MCP-архитектуры.

### zai-one/yandex-mcp
- URL: https://github.com/zai-one/yandex-mcp
- Большой сервер на 127 инструментов: Директ, Метрика, Вебмастер, Wordstat, Search API, Audience.
- Wordstat: топ-запросы, динамика, региональное распределение и дерево регионов.
- Поддержка toolsets, read-only, lazy loading, нескольких аккаунтов и HTTP.
- Важно: source-available лицензия ZAI.ONE 2.0, не свободная для копирования в конкурирующий продукт. Использовать как референс поведения, не брать код без разрешения.

## Другие конкуренты в РФ

### Rush Analytics
- URL: https://www.rush-analytics.ru/land/parser-wordstat-onlajn
- Онлайн-парсер Wordstat и более широкий SEO-инструментарий.
- Есть API подбора ключевых слов, по обзорам тарифы от $49/мес.
- Сильнее как комплексный SEO-инструмент, слабее как дешёвый доступ к одной частоте.

### Keys.so, Pixel Tools, MegaIndex
- Собственные базы ключевых слов, анализ конкурентов и доменов, большие отчёты.
- Подписки и более сложный интерфейс.
- Не прямые замены быстрого запроса «фраза → частота → сезонность» через бота/MCP.

### Serpstat
- Комплексная SEO-платформа: ключевые слова, конкуренты, аудит, позиции.
- По обзорам 2026 старт около $50/мес.
- Для нашего MVP избыточна.

### Bukvarix
- Большая заранее собранная база ключевых слов, есть бесплатные варианты.
- Отличается источник данных: не живой запрос к официальному Wordstat API.

### Расширения и парсеры Вордстата
- Собирают выдачу сайта, требуют аккаунт/прокси/лимиты и ручную работу.
- Наш путь чище: официальный API, кэш, контроль квоты и структурированный ответ.

## Запад

Прямого западного аналога именно Яндекс Вордстата нет: данные региональные.

- Google Keyword Planner — объёмы поиска Google, доступ через рекламный кабинет.
- Ahrefs, Semrush, SE Ranking — подписки, семантика, конкуренты, аудит и мониторинг.
- DataForSEO и другие SEO API — продажа keyword data разработчикам по запросам.
- Западный урок для продукта: простой API и оплата за использование, а не обязательная подписка.

Наше отличие — специализация на Яндексе, русских запросах, регионах РФ и готовых сценариях для русскоязычного контента.

## Что уже есть у нас

- VPS `/opt/seo/wordstat.py`.
- Yandex Cloud Search API v2.
- Широкая частота, `--exact`, `--both`.
- Операторы: кавычки для точной фразы, `!слово` для точной формы.
- Кэш `data/ws_cache.json`: повторный запрос не тратит квоту.
- Квота: 100 запросов в час, обработка 429 и ожидание следующего окна.
- Скрипт подсказок YouTube `yt_suggest.py`, включая добивку алфавитом.
- `merge.py`: фраза × место в подсказках × широкая × точная.
- Опыт очистки интентов, группировки и создания заголовков для YouTube, VK, Rutube, Дзена, Хабра/vc и Telegram.

## Главный вывод

Сам MCP к Вордстату уже не уникален. Marketscore продаёт почти тот же сервис за 0,125–0,20 ₽ за запрос. Бесплатные MCP с собственным ключом тоже есть.

Продукт надо делать не «ещё один endpoint к Wordstat», а готовый рабочий инструмент подбора семантики и контента с нашей методикой.

## Возможные отличия

1. Широкая и точная частота рядом с понятным объяснением, зачем нужны обе.
2. Подсказки YouTube + Вордстат в одной таблице — у Marketscore упор на Яндекс и Директ, у нас дополнительный контентный канал.
3. Готовые сценарии под площадку: YouTube, Shorts, VK, Rutube, Дзен, Хабр/vc, Telegram.
4. Не только частоты, а отобранная семантика без мусора, сгруппированная по интенту.
5. Главный и вторичные ключи + 3–5 заголовков под выбранную площадку с обоснованием цифрами.
6. Настоящая поддержка операторов и разных написаний: «чат gpt», «чат гпт», «chatgpt», «чатгпт».
7. Кэш и прозрачная квота: пользователь видит стоимость операции до запуска.
8. Пакеты без подписки и Telegram-бот для нетехнического пользователя.
9. MCP-инструмент высокого уровня «собери семантику и заголовки», а не только четыре низкоуровневых вызова API.
10. Повторное использование результатов в SEO/GEO/AEO-аудите: общий контентный фундамент для первого проекта.

## Предлагаемые интерфейсы

### Веб-окно

Пользователь вводит тему, регион и площадку. Получает:

- основные варианты написания;
- таблицу фраз и частот;
- широкую и точную частоту;
- место в подсказках YouTube;
- группы по интенту;
- минус-слова;
- сезонность;
- главный/вторичные ключи;
- заголовки;
- экспорт Markdown/CSV.

### Telegram-бот

Примеры команд:

- `/ws ремонт кофемашин` — широкая и точная частота.
- `/exact ремонт кофемашин` — точная.
- `/season детский лагерь` — сезонность.
- `/semantika увлажнитель воздуха youtube` — полный подбор.
- `/titles увлажнитель воздуха youtube` — ключи и заголовки.

Перед тяжёлой операцией бот показывает количество новых API-запросов и доступный остаток квоты.

### Обязательный MCP-сервер

Низкий уровень:
- `wordstat_frequency` — широкая и точная частота.
- `wordstat_related` — похожие запросы и ассоциации.
- `wordstat_dynamics` — динамика и сезонность.
- `wordstat_regions` — распределение спроса и регионы.
- `wordstat_find_region` — название региона → ID.
- `youtube_suggest` — подсказки и место фразы.
- `quota_status` — квота, кэш, стоимость операции.

Высокий уровень:
- `keyword_research` — затравки → подсказки → отбор → частоты → интенты → таблица.
- `platform_keywords` — главный/вторичные ключи под площадку.
- `generate_titles` — 3–5 заголовков с обоснованием запросами.
- `cached_report` — повторная выдача существующего отчёта без новых трат.

## Ограничения и правила

- Не обещать неограниченный API: базовая квота 100 запросов в час.
- Не запускать полный сбор до показа стоимости по новым фразам.
- Кэшировать запросы и готовые отчёты.
- Не смешивать широкую и точную частоту.
- Не выдавать ассоциации за готовую семантику без чистки.
- Не выдумывать цифры, если запрос не выполнен или квота кончилась.
- Не смешивать данные YouTube и Яндекса: место в подсказках ≠ число показов.
- Ключи Yandex Cloud хранить только серверной стороне.

## Предлагаемый MVP

- Один веб-интерфейс или Telegram-бот, не обязательно оба одновременно.
- Широкая+точная частота, похожие запросы, сезонность.
- Полный отчёт по одной теме с нашей таблицей YouTube+Wordstat.
- MCP-сервер с базовыми инструментами и одним высокоуровневым `keyword_research`.
- Кэш, квота, журнал себестоимости.
- Пакеты запросов без подписки.
